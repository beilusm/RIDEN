# RIDEN 2.0.0-1

Windows 兼容性补丁：

- Windows 默认使用软件渲染，并禁用 Java2D Direct3D，避开主窗口最大化或全屏时的 GPU 渲染路径。软件渲染可能增加 CPU 占用。
- MSI 的桌面和开始菜单快捷方式改为无条件安装；升级旧版和修复安装均应恢复快捷方式。
- Windows 构建加入最大化、全屏、恢复窗口的渲染和截图检查，以及 MSI 实际安装、快捷方式目标、修复、卸载和 2.0.0 升级检查。

Windows 可直接安装 MSI 升级 2.0.0，或解压便携 ZIP 后运行 `RIDEN/RIDEN.exe`。修复既有安装可重新运行 MSI，或执行 `msiexec /fas "RIDEN-2.0.0-1-windows-x64.msi"`。

Linux 和 Android 仅同步补丁版本号。发布包自带所需运行时，Android 沿用 2.0.0 发布签名。

全屏闪烁来自用户实机反馈；CI 窗口检查不等同于受影响显卡的实机回归，仍需在原 Windows 主机上确认。真机串口验收仍待完成。
