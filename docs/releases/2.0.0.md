# RIDEN 2.0.0

使用 Compose Multiplatform 重建 Linux、Windows、Android 上位机；完整 Flutter 旧版保留在 `legacy/flutter` 分支。

- PC 使用左侧导航与紧凑顶栏，手机窄屏使用底部导航；预设选择、载入与编辑整合到设定下方。
- Linux 固定中性灰主题，Android 12+ 支持系统动态配色；桌面提供透明置顶悬浮监控。
- V/A/W 独立波形与数值刻度、真实时间轴、最小/最大/平均值；悬停或触摸选点可同步查看三项数据，支持暂停、缩放及自动量程。
- 按电源型号校验设定、OVP/OCP 上限和精度，包含 60067 衍生 ID；未知型号的输出设定保持只读。
- 重写 Modbus 调度、读写校验、自动连接与断连清理；CSV 按采样逐点录制，Android 使用系统文件选择器导出。

## 下载与运行

- Windows x64：安装 `RIDEN-2.0.0-windows-x64.msi`，或解压 ZIP 后运行 `RIDEN/RIDEN.exe`。两者自带 Java 运行时。
- Linux x86_64：为 AppImage 添加执行权限后运行；Debian/Ubuntu 也可安装 DEB。
- Android 5.0+：安装 `RIDEN-2.0.0-android.apk`（发布签名）。与 Flutter 1.x 使用不同应用 ID；已安装的 2.0 Debug 版需先导出数据、卸载后再安装。
- 使用 `SHA256SUMS.txt` 核对下载文件。

## 验证范围

已通过软件核心、协议、型号能力及界面测试，并完成 Linux 演示运行、CSV 导出和 Android 演示/导出验证。发布流程在 Windows runner 编译和打包，在 Linux runner 检查界面、Android 签名及校验文件。

目前没有 RIDEN/CH340 真机和物理 Windows 主机验收。部分型号能力仍需按真实设备核对，详见 [型号能力表](https://github.com/beilusm/RIDEN/blob/v2.0.0/docs/DEVICE_CAPABILITIES.md)。演示数据不代表真实测量。

后续新版本按 `2.0.1`、`2.0.2` 递增；同版补丁按 `2.0.0-1`、`2.0.0-2` 编号，均为正式发布。
